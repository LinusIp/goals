# Dream Board

A quiet night sky of plans and dreams. Each plan is a star until the day it comes true, and then it stays lit.

**Live:** https://linusip.github.io/goals/

Everything lives in [`data/plans.json`](data/plans.json). The page only reads it; plans are added and checked off by editing that file and committing. See [`CLAUDE.md`](CLAUDE.md) for how the board is kept.
